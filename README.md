# E-Commerce Sales Analysis using MySQL

## Project Overview
This project analyzes e-commerce sales data using MySQL. It helps identify sales trends, top-selling products, category performance, and customer spending.

## Tools Used
- MySQL
- SQL

## Database Tables
- Customers
- Products
- Orders
- Order Details

## Key Analysis
- Total Revenue Analysis
- Top-Selling Products
- Category-wise Sales Analysis
- Customer-wise Spending Analysis
- Monthly Sales Analysis

## SQL Concepts Used
- SELECT statements
- WHERE clause
- JOIN operations
- GROUP BY
- ORDER BY
- Aggregate functions such as SUM, COUNT, and AVG
- HAVING clause

## Project File
- `ecommerce_sales_analysis.sql` — Contains SQL queries used for the analysis.

## Objective
The objective of this project is to practice SQL skills and extract meaningful insights from e-commerce sales data.
